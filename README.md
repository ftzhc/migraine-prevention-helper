# 片頭痛 予防薬えらびの目安ツール

福岡天神頭痛と肺のクリニックの医師・スタッフが、診察のときに使う「片頭痛の予防薬えらびの目安」ツールです。
`index.html` の1ファイルだけで動き、GitHub Pages でそのまま公開できます。

> **大切な注意**
> このツールは診察の補助です。%は入力した条件に合う度合いの目安で、効果の確率ではありません。処方は医師が判断します。
> 薬の情報・禁忌・点数のルール・注意書きは**下書き**です。公開前に医師の確認が必要です（確認してほしい点は [CHECKLIST.md](CHECKLIST.md) にまとめています）。

---

## 1. このツールの目的

- 患者さんの条件（頭痛の回数、年齢、妊娠・授乳、持病、副作用の気がかり、鎮痛薬の使いすぎ、試し済みの薬）を画面で入力します。
- 片頭痛の予防薬ごとに「入力した条件にどれだけ合うか」を 0〜100% で計算し、高い順に、理由といっしょに表示します。
- 薬の情報は「頭痛の診療ガイドライン2021」（日本神経学会・日本頭痛学会・日本神経治療学会）の予防療法の章（CQ II-3-1〜3）を中心に、薬の使い分け（CQ II-3-4・5）、各薬の項（CQ II-3-6〜10・14）、妊娠・授乳（CQ II-2-13）、漢方薬（CQ I-14）、小児・思春期（CQ VII-5）の要点を、このツール用に言いかえてまとめたものです。ガイドラインの文章そのものや PDF はリポジトリに入れていません。
- 推奨の強さ・エビデンスの確実性・薬効 group・用量は、ガイドライン2021の予防薬の表（CQ II-3-2 表1・表2）と照合してあります。

## 2. できること・できないこと

| できること | できないこと |
|---|---|
| 条件に合う薬を目安として並べる | 効く確率を出す（%は確率ではありません） |
| 禁忌にあたる可能性のある薬を灰色で知らせる | 処方の最終判断（医師が行います） |
| 予防療法の目安、鎮痛薬の使いすぎ（MOH）の注意を出す | 入力内容の保存（保存も送信もしません） |

## 3. 使い方

1. 公開した URL（または `index.html`）をブラウザで開きます。スマホ・タブレット・パソコンのどれでも使えます。
2. 左側（スマホでは上側）の入力欄に、患者さんの条件を入れます。入力するたびに、右側（スマホでは下側）の結果がすぐに更新されます。
3. 結果の一番上に、注意（鎮痛薬の使いすぎ、予防薬が必要ない可能性、妊娠・授乳 など）が出ます。
4. 薬のカードは %の高い順に並びます。カードには次のものが表示されます。
   - %の棒グラフ
   - 推奨グレードと group、保険の扱い
   - 用量の目安
   - 点数の内訳（「＋20 高血圧の治療にもなるため」「−20 眠気が気になるため」など）
   - 主な副作用、補足・注意事項
5. 次の患者さんに移るときは「入力をすべて消す」ボタンを押します。画面を閉じても入力は残りません。

### 画面に出るしるしの意味

| しるし | 意味 |
|---|---|
| 使えない可能性 | 禁忌にあたる条件が入力されています。0% にして一番下に灰色で表示します |
| 注意 | 慎重に使う条件にあたるため減点しています |
| 強い注意 | 妊娠中など、特に慎重な条件にあたります |
| 試し済み | 既に試して効かなかった・続けられなかった薬です（大きく減点） |
| 保険で使う条件を満たさない可能性（要確認） | 抗CGRP抗体の保険の条件（月4日以上の片頭痛日数、既存の予防薬が効かない・使えない）にあたらない入力です |

カードの上に出る「推奨の強さ（強い／弱い）」「エビデンス A／B／C」「薬効 group」「副作用の頻度」は、ガイドライン2021の予防薬の表（表1）の列です。
薬効 group（表2）：1＝有効、2＝ある程度有効、3＝経験的に有効、4＝有効だが副作用に注意、5＝無効。
依頼のときの「推奨グレード A/B/C」は、この表の「エビデンスの確実性」にあたります。

## 4. 対象の薬（ツールに入れているもの）

ガイドライン2021の表1（予防薬エビデンスサマリ）と照合した値です。

| 薬（商品名） | 推奨の強さ | エビデンスの確実性 | 副作用の頻度 | 薬効 group | 1日量の目安（表1の推奨用量） | 保険の扱い（ツール内の表示） |
|---|---|---|---|---|---|---|
| ガルカネズマブ（エムガルティ） | 強い | A | まれ | 1 | 120mg 月1回 皮下注（初回のみ240mg） | 適用。ただし使用条件あり |
| フレマネズマブ（アジョビ） | 強い | A | まれ | 1 | 225mg 4週に1回 または 675mg 12週に1回 皮下注 | 適用。ただし使用条件あり |
| エレヌマブ（アイモビーグ） | 強い | A | まれ | 1 | 70mg 4週に1回 皮下注 | 適用。ただし使用条件あり |
| バルプロ酸（デパケン など） | 強い | A | 時々〜頻繁 | 1 | 400〜600mg | 適用 |
| プロプラノロール（インデラル） | 強い | A | まれ〜時々 | 1 | 20〜60mg | 適用 |
| アミトリプチリン（トリプタノール） | 強い | A | 頻繁 | 1 | 10〜60mg | 適応外だが保険診療での使用が認められている（表1の＊） |
| ロメリジン（ミグシス） | 弱い | B | まれ | 2 | 10〜20mg | 適用 |
| カンデサルタン（ブロプレス など） | 弱い | B | まれ | 2 | 8〜12mg | 適用外（表1の＊＊） |
| 呉茱萸湯（漢方） | 空欄 | 空欄 | 空欄 | 空欄 | 製品による | 要確認 |

呉茱萸湯は予防薬の表には入っていません。第Ⅰ章 CQ I-14「頭痛診療において漢方薬は有効か」で、漢方薬全体として「弱い推奨／エビデンスの確実性B」とされています。ツールでは空欄のまま「要確認」にしています。

## 5. %の計算のしかた（要点）

1. 薬ごとに**基本点**があります（エビデンスの確実性 A＝70、B＝50、呉茱萸湯（表にない）＝30）。
2. 入力した条件にあたるごとに、点を足したり引いたりします（例：高血圧 → プロプラノロール ＋20、眠気が気になる → アミトリプチリン −20）。
3. 禁忌にあたる薬は 0% にして「使えない可能性」と表示します。慎重に使う条件は減点して「注意」と表示します。
4. 既に試して効かなかった薬は −40 して「試し済み」と表示します。
5. 抗CGRP抗体は、月の頭痛日数が4日以上で、既存の飲み薬の予防薬（バルプロ酸・プロプラノロール・アミトリプチリン・ロメリジン）が「試し済み」のとき ＋15。試し済みはないが禁忌で使えない飲み薬があるときは ＋5（要確認）。どちらにもあたらないときは −30 して「保険で使う条件を満たさない可能性（要確認）」と表示します。
6. 最後に 0〜100 の範囲にそろえます。

## 6. 点数ルールの直し方（プログラムの専門家でなくても直せます）

薬の情報と点数のルールは、すべて `index.html` の中の **`<script>` のすぐ下にある `const DATA = { ... }`** という1か所にまとめています。
日本語のコメント（`//` や `/* */` で始まる行）に説明を書いていますので、その中の数字や文章だけを直してください。それより下の「プログラム本体」は触らなくて大丈夫です。

### どこの数字を変えればよいか

| 変えたいこと | 直す場所 |
|---|---|
| ある薬の出発点を上げ下げしたい | その薬の `基本点: 70` の数字 |
| 条件にあたったときの点を変えたい | その薬の `調整: [ ... ]` の中の `点: 20` や `点: -20` の数字 |
| 加点・減点の理由の文章を変えたい | 同じ行の `理由: '...'` の文章 |
| 「注意」ではなく「禁忌（0%）」にしたい（またはその逆） | 同じ行の `種類: '注意'` を `種類: '禁忌'` に（禁忌のときは `点` は不要） |
| 新しい条件のルールを足したい | `調整: [ ... ]` の中に `{ 条件: '高血圧', 種類: '加点', 点: 10, 理由: '...' },` の形で1行足す（条件の名前は DATA の上のコメントにある一覧から選ぶ） |
| 試し済みの減点を変えたい | `共通` の `試し済みの減点: -40` |
| 抗CGRP抗体の保険条件の点や日数を変えたい | `共通` の `抗CGRP抗体の保険条件: { ... }` |
| 予防療法の目安（月2回・月3日）を変えたい | `共通` の `予防療法の目安: { ... }` |
| 年齢の区切り（18歳・25歳・65歳）を変えたい | `共通` の `年齢の区切り: { ... }` |
| 用量・保険の扱い・副作用・補足の文章を変えたい | その薬の `用量:` `保険:` `副作用:` `補足:` |
| 推奨の強さ・エビデンス・副作用の頻度・group の表示を変えたい | その薬の `推奨の強さ:` `グレード:`（エビデンスの確実性） `副作用の頻度:` `グループ:` |
| 最終更新日・医師確認の表示を変えたい | DATA の一番上の `更新日:` と `医師確認:` |

### 直すときの注意

- 文章は `'` と `'` の間に書きます。文章の中に `'` を入れないでください（必要なら全角の ’ を使います）。
- 行の終わりの `,` は消さないでください。
- 数字は半角で書きます。引く点はマイナス（`-20`）で書きます。
- 直したあとは、ツールの「動作確認用の例を入れる」ボタンで3つの例を入れて、おかしな結果になっていないか見てください。

### GitHub の画面で直す手順

1. GitHub でこのリポジトリを開き、`index.html` をクリックします。
2. 右上の鉛筆のマーク（Edit this file）を押します。
3. 直したい数字や文章を書きかえます。
4. 右上の「Commit changes...」を押し、変更の内容（例：「アミトリプチリンの眠気の減点を −15 に変更」）を書いて「Commit changes」を押します。
5. GitHub Pages で公開している場合は、1〜2分ほどで公開ページにも反映されます。

## 7. GitHub Pages での公開手順

1. GitHub でこのリポジトリを開き、上のタブの「Settings」を押します。
2. 左のメニューの「Pages」を押します。
3. 「Build and deployment」の「Source」で「Deploy from a branch」を選びます。
4. 「Branch」で公開したいブランチ（通常は `main`）と、フォルダ「/ (root)」を選び、「Save」を押します。
5. 1〜2分待つと、同じ画面の上のほうに公開 URL（例：`https://ユーザー名.github.io/migraine-prevention-helper/`）が表示されます。その URL を開くとツールが使えます。
6. ページには `noindex` を入れているので、検索エンジンには載りにくくなっています。ただし URL を知っていれば誰でも開けるため、URL は院内だけで共有してください。

（このツールは外部のライブラリやフォントを読み込まず、サーバーやデータベースも使いません。`index.html` を置くだけで動きます。）

## 8. 動作確認の例

「動作確認用の例を入れる」ボタンで同じ入力ができます。2026-11-05 時点のルールでの結果です。

### 例1：高血圧のある中年の方

入力：発作 4回／月、支障のある頭痛 4日／月、頭痛日数 6日／月、重さ「中くらい」、急性期治療薬は効いている（いいえ）、52歳、持病「高血圧」。

| 順位 | 薬 | % | 主な理由・表示 |
|---|---|---|---|
| 1 | プロプラノロール | 90 | ＋20 高血圧をいっしょに治療できるため |
| 2 | カンデサルタン | 75 | ＋25 高血圧がある片頭痛の予防に有効。高血圧の治療として保険で処方できる（片頭痛には保険適用外の表示あり） |
| 3 | バルプロ酸 | 70 | 基本点のみ |
| 4 | アミトリプチリン | 70 | 基本点のみ |
| 5 | ロメリジン | 50 | 基本点のみ |
| 6 | ガルカネズマブ | 40 | −30 保険で使う条件を満たさない可能性（既存の予防薬が効かなかった・使えないという入力がない） |
| 7 | フレマネズマブ | 40 | 同上 |
| 8 | エレヌマブ | 35 | 同上 ＋ −5 注意（血圧上昇の報告） |
| 9 | 呉茱萸湯 | 30 | 基本点のみ（推奨度は空欄・要確認） |

上の注意：「予防療法を検討する目安に当たります」。
→ 高血圧があるとプロプラノロールとカンデサルタンが加点され、抗CGRP抗体は保険条件の注意が出る、というルールどおりです。

### 例2：喘息とうつのある若い女性

入力：発作 3回／月、支障のある頭痛 3日／月、頭痛日数 5日／月、重さ「中くらい」、急性期治療薬は効いている（いいえ）、28歳、持病「喘息」「うつ」、「妊娠できる年齢の女性（今は妊娠の予定なし）」にチェック。

| 順位 | 薬 | % | 主な理由・表示 |
|---|---|---|---|
| 1 | アミトリプチリン | 90 | ＋20 うつの治療にもなるため。※妊娠中に予防薬が必要な場合の選択肢に挙げられている薬 |
| 2 | ガルカネズマブ | 70 | ＋5 既存の飲み薬の予防薬に使えないもの（プロプラノロール）があるため（保険条件に当たる可能性・要確認）、−5 注意（半減期が長く妊娠の計画に注意） |
| 3 | フレマネズマブ | 70 | 同上 |
| 4 | エレヌマブ | 70 | 同上 |
| 5 | バルプロ酸 | 50 | −20 注意：妊娠できる年齢の女性では第一選択としない（ガイドライン） |
| 6 | ロメリジン | 40 | −5 注意（抑うつに注意）、−5 注意（妊娠がわかった時点で中止が必要） |
| 7 | カンデサルタン | 40 | −10 注意（妊娠がわかった時点で中止が必要）。保険適用外の表示あり |
| 8 | 呉茱萸湯 | 30 | 基本点のみ |
| － | プロプラノロール | 0 | **使えない可能性**：喘息ではβ遮断薬は禁忌。灰色で一番下 |

→ 喘息でプロプラノロールが除外され、うつでアミトリプチリンが加点される、というルールどおりです。
（「妊娠の可能性がある」にチェックすると、バルプロ酸・カンデサルタン・ロメリジンが除外され、ほかの薬に強い注意がつきます。）

### 例3：予防薬を2種類試して効かなかった、月8日片頭痛の方

入力：発作 5回／月、支障のある頭痛 6日／月、頭痛日数 8日／月、重さ「重い・寝込む」、急性期治療薬で十分に効かない（はい）、45歳、試し済み「プロプラノロール」「ロメリジン」。

| 順位 | 薬 | % | 主な理由・表示 |
|---|---|---|---|
| 1 | ガルカネズマブ | 85 | ＋15 月の頭痛日数が4日以上で、既存の飲み薬の予防薬（プロプラノロール・ロメリジン）が効かなかった・続けられなかったため（保険で使う条件の目安） |
| 2 | フレマネズマブ | 85 | 同上 |
| 3 | エレヌマブ | 85 | 同上 |
| 4 | バルプロ酸 | 70 | 基本点のみ |
| 5 | アミトリプチリン | 70 | 基本点のみ |
| 6 | カンデサルタン | 50 | 基本点のみ |
| 7 | プロプラノロール | 30 | −40 試し済み |
| 8 | 呉茱萸湯 | 30 | 基本点のみ |
| 9 | ロメリジン | 10 | −40 試し済み |

→ 月4日以上で既存薬が効かなかったため抗CGRP抗体が加点され、試し済みの薬は大きく減点される、というルールどおりです。

### そのほか確認したこと

- 鎮痛薬の使いすぎにチェックすると、一番上に赤い枠で MOH の注意が出ます。
- 発作が月2回未満かつ支障のある頭痛が月3日未満のときは「予防薬が必要ない可能性があります」が一番上に出ます。
- 妊娠中にチェックすると、バルプロ酸・カンデサルタン・ロメリジンが 0%（使えない可能性）になり、ほかの薬に「強い注意」がつきます。プロプラノロールと少量のアミトリプチリンは、妊娠中に予防薬が必要な場合の選択肢として挙げられている旨を表示します（ガイドライン CQ II-2-13）。
- 18歳未満では抗CGRP抗体が 0%（成人が対象）になり、バルプロ酸に注意がつきます。プロプラノロール・アミトリプチリン・ロメリジンは小児・思春期の選択肢であることを表示します（CQ VII-5）。
- 外部への通信、保存（localStorage など）は一切ありません。ブラウザのコンソールにエラーは出ません。
- スマホ幅（390px）で横スクロールが出ないことを確認しました。
